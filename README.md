# 🛠️ Mat's Forge

**Mat's Forge** est une application web/mobile permettant de **créer et gérer des fiches de personnages personnalisées** pour jeux de rôle, jeux de plateau et univers narratifs.

L'application fonctionne directement dans le navigateur et peut être installée comme **application mobile (PWA)**.

---

## 🎲 Fonctionnalités principales

✅ Création de fiches de personnages personnalisées
✅ Templates intégrés pour de nombreux systèmes JdR
✅ Mode édition / mode jeu
✅ Sauvegarde locale automatique
✅ Import / Export des personnages
✅ Lanceur de dés intégré
✅ Gestion des états, ressources et inventaires
✅ Interface optimisée mobile
✅ Mode sombre / clair

Mat's Forge permet de jouer **sans papier**, directement depuis smartphone ou tablette.

## 📱 Installation (Application Mobile)

Mat's Forge peut être installé comme une vraie application :

### Android / Chrome

1. Ouvrir l'application dans le navigateur
2. Menu ⋮
3. **Ajouter à l'écran d'accueil**

### iOS / Safari

1. Ouvrir l'application
2. Bouton **Partager**
3. **Sur l'écran d'accueil**

---

## 💾 Sauvegarde des données

Les personnages sont stockés localement dans votre navigateur.

Vous pouvez :

* Exporter vos fiches en `.json`
* Importer vos sauvegardes
* Continuer hors ligne
